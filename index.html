BlockPy for IgniteICT

A web-based Python environment for education and data science

About BlockPy for IgniteICT

BlockPy for IgniteICT is a web-based Python environment that lets you work with blocks, text, or both. Designed for Data Science and equipped with powerful tools like the State Explorer and Guided Feedback, the goal of BlockPy for IgniteICT is to let you solve authentic, real-world problems.

The goal of BlockPy for IgniteICT is to give you a gentle introduction to Python but eventually mature you into a more serious programming environment (such as Spyder or PyCharm).

Try BlockPy for IgniteICT View on GitHub

Key Features

Block-Based Coding

Drag and drop blocks to build Python programs without worrying about syntax errors.

Text Editor Integration

Seamlessly switch between blocks and text mode as you develop your coding skills.

Data Science Focus

Built specifically for data analysis and visualization tasks with specialized blocks.

Guided Feedback

Receive intelligent feedback on your code to help you learn and improve.

State Explorer

Visualize program execution to understand what your code is doing step by step.

Client-Side Execution

Everything runs in your browser - no need for server-side processing.

Installation

For developers interested in setting up BlockPy for IgniteICT locally:

# Clone the repository
git clone https://github.com/kafiBrejawi/blockpy-for-igniteict.git
cd blockpy-for-igniteict

# Install dependencies
npm install

# Run development server
npm run dev

For more detailed installation instructions, please refer to the GitHub repository.
